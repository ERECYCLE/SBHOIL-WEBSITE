08 / Technical Guide

SAE viscosity and API performance

The catalog explains SAE viscosity-temperature grading: W grades relate to low-temperature performance, while hot grades such as 20, 30, 40, 50 and 60 describe higher-temperature viscosity behavior. Multigrades such as 5W-40 combine cold- and hot-temperature characteristics.

The catalog also explains API performance categories, including S for gasoline-service applications and C for commercial diesel applications; slash-separated categories indicate dual gasoline/diesel positioning.
